# Pitcher v0.3 — голосовой питч/формант процессор + Voice Transform (VST3)

Windows 10/11, FL Studio (и любой DAW с VST3). Моно/стерео. Задержка сообщается хосту, FL компенсирует её сама.

---

## Что нового в v0.3

1. **Новый движок Live (по умолчанию): задержка 32 мс вместо 85 мс.** Это принцип голосовых процессоров типа Little AlterBoy: слежение за высотой голоса + PSOLA (зёрна по периодам голоса). Тембр живее и естественнее, чем у фазового вокодера, формант сдвигается независимо от питча. Старые движки остались как **Smooth 2048 / Smooth 4096** (для сложного материала, не только голоса).
2. **Шкалы как в Little AlterBoy:** PITCH и FORMANT в полутонах, ноль по центру, ±12, двойной клик — сброс. Кнопка **Transpose** привязывает PITCH к целым полутонам. Ручка FINE убрана (PITCH и так плавный).
3. **Voice Transform — отдельный эффект** с семью характерами и ручкой **VOICE AMOUNT**. Ручки PITCH и FORMANT он не трогает: они остаются полностью твоими.

## 1. Сборка через GitHub (один раз ~10 минут)

1. github.com → **New repository** → `Pitcher` → **Create repository**.
2. **uploading an existing file** → перетащи **всё содержимое папки Pitcher** (папки `Source`, `Tests`, `Assets`, `CMakeLists.txt`, `.gitignore` и скрытую `.github`).
   - Если `.github` не загрузилась: **Add file → Create new file**, имя `.github/workflows/build.yml`, вставь содержимое файла `build.yml`.
3. **Commit changes**.
4. Вкладка **Actions**: запустится сборка (3–8 мин): `dsp-tests` (автотесты звука, должна быть зелёная) и `build-windows-vst3` (сама сборка).
5. Когда всё зелёное: открой запуск → внизу **Artifacts** → скачай `Pitcher-VST3-Windows`.
6. Если красное: скопируй последние ~40 строк красного лога и пришли мне.

Если ты уже заливал v0.1/v0.2 в тот же репозиторий: просто замени файлы новыми (Add file → Upload files, перезапись).

## 2. Установка

1. Распакуй zip → внутри **`Pitcher.vst3`** (папка с `Contents\x86_64-win\Pitcher.vst3`; копируй целиком).
2. Положи в `C:\Program Files\Common Files\VST3\`.
3. FL Studio → **Options → Manage plugins → Find installed plugins**. Pitcher появится в Installed → Effects.
4. На дорожку микшера: слот эффекта → **Pitcher**.

## 3. Управление

| Элемент | Что делает |
|---|---|
| **VOICE** | Выбор характера (см. ниже). Отдельный эффект: PITCH/FORMANT не двигаются |
| **VOICE AMOUNT** | Сила характера, 0–100 %. 0 = исходный голос, плавно до полного превращения |
| **PITCH** | ±12 полутонов, ноль по центру |
| **FORMANT** | ±12 полутонов, независимо от питча. «+» голос «меньше/светлее», «−» «больше/гуще» |
| **Transpose** | Включено: PITCH шагает целыми полутонами |
| **Preserve formants** | ВКЛ: форманты остаются на месте при смене питча. ВЫКЛ: обычный «ленточный» питчшифт, форманты едут с питчем |
| **Quality** | **Live** (32 мс, для голоса) / Smooth 2048 (43 мс) / Smooth 4096 (85 мс, самый плавный, для сложного материала) |
| **Voice range** | Подсказка трекеру (Low/Mid/High). Для вокала Mid; для детских/высоких голосов High |
| **MIX / OUTPUT** | Баланс сухого/обработанного (сухой выровнен по задержке) / уровень |

В шкале AlterBoy PITCH ±12 (в PRO-версии ±24). Для FORMANT открытые источники называют типичную шкалу ±12 st; точное отображение его ручки я проверить не смог, поэтому сделал так же.

## 4. Voice Transform: 7 характеров

Это отдельный модуль плагина, который превращает голос в выбранный характер. Он меняет не только питч и форманту, но и **интонацию** (ширину мелодики), **вибрато**, **придыхание**, **тембр** (4-полосная коррекция: грудной резонанс, «присутствие», «воздух») и **пространство**.

| Характер | Что происходит с голосом |
|---|---|
| **Anime voice** | питч +4.5 st, форманта +4 st, мелодика живее (×1.35), воздух в верхах, облегчённые низы, акцент на «присутствие» ~3 кГц |
| **Male voice** | питч −4 st, форманта −3.5 st, мелодика спокойнее (×0.8), грудной резонанс (170–450 Гц), приглушённые верха |
| **Woman voice** | питч +3.5 st, форманта +2.5 st, мелодика ×1.15, лёгкое придыхание, мягкая яркость |
| **Baby voice** | питч +8 st, форманта +6.5 st, мелодика ×1.5, дрожащее вибрато (±25 центов, 7 Гц), яркость |
| **Robot voice** | питч фиксируется на 110 Гц (монотон, независимо от того, как поёшь), форманты остаются; ручка PITCH двигает высоту робота. В Smooth-режимах это вокодер-робот |
| **Big echo voice** | голос чуть глубже, огромный зал: эхо 340/430 мс + реверб |
| **Super pitch up voice** | питч +12 st, форманта +6 st, мелодика ×1.2, яркость |

**Честно о том, что это такое.** Это не нейросеть. Настоящая нейросетевая смена голоса (как RVC) требует обученных моделей под каждый голос, а обучить их здесь невозможно (нет GPU и датасетов); к тому же такие модели обычно дают задержку 200–500 мс и сильно грузят процессор. Voice Transform — это максимум, который можно сделать внутри плагина классической обработкой в реальном времени: он надёжно и предсказуемо меняет тип и характер голоса, но не «клонирует» конкретного человека и не заменяет тембр целиком, как нейросеть. Если нужна именно нейросетевая конверсия, следующий шаг — подключить в плагин ONNX-модели (для этого нужны обученные модели под 7 характеров, их нужно взять или обучить отдельно, плагин для их запуска я могу сделать).

Советы: AMOUNT 60–100 % для явного превращения; Preserve = ВКЛ. Сдвиги относительные: низкий мужской голос + Male станет ещё ниже, в таких случаях подправь ручками PITCH/FORMANT.

## 5. Проверено автотестами (77 штук, идут на каждой сборке)

Звук проверен отдельно от окна плагина на синтетическом «живом» голосе (глиссандо, вибрато, дрожание тона, смена гласных, шипящие, паузы):
- **Задержка Live ровно 1536 сэмплов = 32 мс** (Smooth 4096: 85 мс); при нулевых сдвигах голос проходит бит-в-бит (SNR 152 дБ);
- **Высота на живой речи:** медианная ошибка ≈ 0–2 цента при сдвигах от −12 до +12 st;
- чистота: гармоники/шум > 37 дБ, громкость сохраняется (±1.2 дБ);
- форманты (Live): при смене питча остаются на месте (ошибка 0.2–0.4 дБ), независимый сдвиг формант ±4/±8 st (≤ 0.7 дБ);
- характеры: питч каждого попадает в цель с точностью до 2 центов, AMOUNT масштабирует, ручки складываются с характером, интонация ×1.5 и ×0.8 измеряется как заявлено (1.47 и 0.79), вибрато Baby ≈ 24 цента (задано 25), Robot держит 110 Гц (разброс 2 цента) при глиссандо на входе, Big echo затухает;
- стресс всех характеров и движков, а также санитайзеры памяти (ASan/UBSan) на 22.05/44.1/48/96 кГц: без ошибок памяти, NaN и бесконтрольных выбросов;
- нагрузка Live ≈ 2% одного ядра на канал.

**Границы проверки:** оболочка плагина (JUCE) не собиралась в моём окружении, первая сборка на GitHub покажет ошибки компиляции, если они есть. Живой вокал и вкус («звучит ли Anime как аниме») оцениваешь ты.

**Ограничения Live:** он для **одноголосого** материала (вокал, речь), не для аккордов и миксов; голоса ниже ~70 Гц не отслеживаются (для них Smooth); задержка 32 мс фиксирована.

## 6. Как прислать дизайн

1. **Полный макет одним PNG** в двойном размере: окно 640×480 → картинка 1280×960 (или скажи свой размер).
2. **Элементы отдельными PNG с прозрачным фоном, вырезанные из того же макета без масштабирования**, чтобы я нашёл координаты автоматически: фон без ручек и текста; ручка (основание + вращающийся указатель «стрелка вверх», либо спрайт-лист 64–128 кадров); переключатели (вкл/выкл); списки; логотип.
3. **Шрифты** (`.ttf`) и **цвета HEX**.

PNG надёжнее SVG (тени/градиенты). Файлы кладутся в `Assets`, остальное сделаю я.
