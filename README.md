# ZCRUSH — VST3 битcrusher (Windows 10/11, FL Studio)

## Как собрать на GitHub
1. Создай новый репозиторий на github.com (Private или Public — без разницы).
2. Загрузи в него ВСЕ файлы из этой папки, включая скрытую папку `.github` (проще всего: GitHub Desktop или `git push`).
3. Открой вкладку **Actions** → workflow **Build ZCRUSH VST3 (Windows)** запустится сам
   (или нажми **Run workflow**). Сборка занимает ~10–15 минут (JUCE качается автоматически).
4. Когда будет зелёная галочка — открой запуск и внизу в **Artifacts** скачай `ZCRUSH-VST3-Windows`.

## Установка в FL Studio
1. Распакуй архив — внутри папка `ZCRUSH.vst3`.
2. Скопируй её целиком в `C:\Program Files\Common Files\VST3\`.
3. FL Studio → **Options → Manage plugins** → **Find installed plugins** (Start scan).
4. Найди **ZCRUSH** в списке (категория Fx), добавь на канал микшера.

## Управление
- **CRUSH** — общая сила эффекта: 0% — чистый звук, 100% — полные значения BIT DEPTH и SAMPLE RATE.
  От неё же двигается пресс и «кровь» в окне.
- **BIT DEPTH** — разрядность (1–16 бит, 8.0 по умолчанию).
- **SAMPLE RATE** — понижение частоты дискретизации, 1/1.0 … 1/32.
- **DRY/WET** — баланс сухого/обработанного.
- **OUTPUT** — выходной уровень, −24…+12 дБ.
- **BYPASS** — обход эффекта.
- Двойной клик по ручке — сброс к значению по умолчанию.
